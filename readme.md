# 🏫 Recull d'Aplicacions Educatives

Portal web principal d'accés ràpid i centralitzat a la col·lecció d'eines web interactives, jocs i activitats gamificades per al treball a l'aula d'**Educació Primària** (i Educació Infantil en alguns recursos).

🌐 **Accés directe al portal:** <https://cromer23cat.github.io/eineseducatives/>

## 📚 Àrees de coneixement

* **📐 [Matemàtiques](https://cromer23cat.github.io/matematiques/)** — Càlcul mental ràpid i global, taules de multiplicar, piràmides numèriques, atzar, funcions i raonament geomètric.

* **📚 [Llengua Castellana](https://cromer23cat.github.io/castellano/)** — Minijocs d'accentuació, ortografia de la B/V, determinants, substantius i activitats per unitats didàctiques.

* **🌍 [Medi (Cicle Superior)](https://cromer23cat.github.io/mediCS/)** — Recursos interactius i qüestionaris sobre l'Edat Mitjana, els éssers vius, les institucions i els paisatges.

## 🛠️ Tecnologies utilitzades

Totes les aplicacions del recull estan desenvolupades amb tecnologies web estàndard, lleugeres i accessibles des de qualsevol dispositiu (ordinador, tauleta o pissarra digital) sense necessitat d'instal·lació:

* **HTML5** per a l'estructura semàntica.

* **Tailwind CSS** per al disseny responsiu i la interfície visual.

* **JavaScript (Vanilla)** per a la lògica dels jocs, la generació aleatòria d'activitats i la retroacció immediata.

## 🚀 Ús a l'aula

El portal està pensat tant per a la projecció en gran grup (PDI / panell interactiu) com per al treball autònom de l'alumnat amb dispositius individuals, facilitant un accés visual i ordenat per àrees a tots els recursos.
